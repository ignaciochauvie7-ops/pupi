# Pupi

SaaS B2B de **inteligencia operativa**: diagnósticos claros y accionables para consultores y dueños de negocio.

## Fase actual

Solo **landing de marketing** en `/` y placeholders en `/login` y `/registro`. Sin dashboard, auth, base de datos ni APIs de negocio.

## Requisitos

- Node.js 20+

## Comandos

```bash
npm install
npm run dev
```

Abrí [http://localhost:3000](http://localhost:3000).

## Próximas fases (no implementadas)

- Autenticación y roles (consultor, dueño, empleado)
- Prisma / Postgres
- Diagnóstico con IA y carga de datos operativos

Variables de entorno de referencia: [.env.example](.env.example).
